# Installation Guide

This section covers different ways to set up and run the AzureShield IAM platform.

## Prerequisites

Before you begin, ensure you have the following installed:

- Docker and Docker Compose
- Node.js 18+ and npm
- Python 3.11+
- Azure CLI (for cloud deployment)

## Installation Methods

Choose the installation method that best suits your needs:

1. [Local Development Setup](./local-development.md) - For developers working on the platform
2. [Docker Deployment](./docker-deployment.md) - For quick deployment using Docker containers
3. [Production Deployment](./production-deployment.md) - For setting up a production environment
